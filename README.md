# interview-practice
微信小程序｜多岗位面试刷题工具，欢迎体验并提交反馈，源码暂不开放

## ✨ 项目简介
这是一款面向职场人的面试刷题微信小程序，覆盖**程序员、产品经理、运营、市场等多个岗位**面试内容。
本仓库仅作为产品展示主页，**不提供源码下载**，欢迎体验小程序并提交反馈，帮助持续迭代优化。

## 🚀 核心功能
- 📚 分岗位题库：技术/产品/运营/市场等岗位面试真题，按岗位分类
- ⏱️ 模拟面试模式：计时作答，还原真实面试场景
- 📝 错题本 & 个人笔记：收藏题目，记录答题思路
- 🔍 多维度检索：按岗位、难度、标签快速筛选面试题

## 📱 如何体验
微信搜索小程序：【填写你的小程序名字】，直接打开体验。

## 💬 提交反馈
使用过程中，欢迎提交你的想法：
- ✅ 哪些功能好用
- ❌ 哪些地方不好用、存在bug
- 💡 期待新增岗位、新功能

反馈两种方式：
1. 在本仓库提交 **Issues**（推荐，方便我分类、跟踪、汇总所有意见）
2. 小程序内【意见反馈】入口，直接提交

我会定期整理所有反馈，迭代更新小程序。

## 🛠️ 技术简述
微信小程序原生开发，Node.js后端，MySQL数据库。
